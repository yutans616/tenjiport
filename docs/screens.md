# 画面一覧（MVP）

作成日：2026-09-08
関連：[exhibitor_saas_design_brief.md](./exhibitor_saas_design_brief.md) / [implementation-plan.md](./implementation-plan.md)

## 主催者側

| # | 画面 | 主要要素・操作 | 対応フェーズ |
|---|---|---|---|
| O1 | サインアップ/ログイン | メール+パスワード or マジックリンク。組織作成（初回）。 | Phase 1 |
| O2 | 組織設定 | 組織名・請求先メール、メンバー招待/権限（owner/admin/staff）。 | Phase 1 |
| O3 | イベント一覧 | 開催名・状態（下書き/公開/終了）・出展者数バッジ、新規作成ボタン。 | Phase 1 |
| O4 | イベント作成・編集 | 名称・会場・開催日・利用期間設定。 | Phase 1 |
| O5 | イベントダッシュボード | 現在出展者数、提出状況内訳、未確認資料件数、未入金件数、通知失敗件数へのショートカット。 | Phase 2〜5（段階的に情報を追加） |
| O6 | フォーム設定・共有URL | セクション/フィールド追加（型・必須・説明・並び順・締切・条件分岐）、プレビュー、公開URL発行・失効。 | Phase 2 |
| O7 | 出展者一覧 | ステータス・グループでフィルタ、検索、一括CSV書き出し導線。 | Phase 2 |
| O8 | 出展者詳細 | 提出内容表示、提出版履歴、修正依頼ボタン、担当者情報。 | Phase 2 |
| O9 | 重複登録レビュー | 重複候補一覧（メール一致/類似社名）、統合/却下。 | Phase 2 |
| O10 | 資料一覧 | 下書き/公開済み、版番号、対象、確認率。 | Phase 3 |
| O11 | 資料作成・編集・公開 | タイトル・本文・添付・対象・確認要求ON/OFF・「公開して通知」。 | Phase 3 |
| O12 | 資料詳細・確認状況 | 出展者ごとの確認状態、未確認者への再通知、送信ログ。 | Phase 3 |
| O13 | 請求書一覧 | 出展者・金額・期限・請求書確認状態・入金状態のクロス表。 | Phase 4 |
| O14 | 請求書作成・編集 | PDFアップロード、金額、個別期限、対象出展者選定。 | Phase 4 |
| O15 | 入金確認 | 未入金→入金済み手動切替、入金日入力、内部メモ、変更履歴表示。 | Phase 4 |
| O16 | データ出力 | テンプレート選択、列選択、権限フィルタ適用済みダウンロード。 | Phase 7（基本CSVはPhase 2から） |
| O17 | プラン・課金管理 | 現プラン種別、現在数と累計課金対象数、見込み請求額、カード登録、決済履歴、プラン変更。 | Phase 5〜6 |
| O18 | 通知失敗/監査ログ | 失敗通知の再送、主要操作の変更履歴閲覧（owner限定）。 | Phase 3・7 |
| O19 | 特定商取引法に基づく表記 | 事業者名・所在地・連絡先等の静的ページ（ブラッシュアップ提案）。 | Phase 7 |

## 出展者側

| # | 画面 | 主要要素・操作 | 対応フェーズ |
|---|---|---|---|
| E1 | 入力エントリー | イベント名・主催者名表示、「入力を始める」（ログイン不要）。 | Phase 2 |
| E2 | メール確認 | メールアドレス入力→確認コード/マジックリンク送信→照合。 | Phase 2 |
| E3 | フォーム入力 | セクション分割入力、自動保存、条件分岐表示、途中離脱→再開リンク。 | Phase 2 |
| E4 | 提出確認・完了 | 入力内容プレビュー、提出ボタン、完了画面。 | Phase 2 |
| E5 | 自社イベントページ | 提出状況、未確認資料バッジ、資料一覧、請求書・支払期限・入金状態。 | Phase 2〜4（段階的に情報を追加） |
| E6 | 資料詳細 | 本文・添付表示、ダウンロード、「確認しました」ボタン。 | Phase 3 |
| E7 | 請求書詳細 | PDF表示、金額・期限・入金状態、「内容を確認しました」操作。 | Phase 4 |
| E8 | 修正依頼対応 | 指摘項目ハイライト+コメント、再提出。 | Phase 2 |
| E9 | ブランドプロフィール | 保存済み情報の閲覧・編集、次回イベントへの再利用選択。 | Phase 2 |
| E10 | ログイン（再訪問） | メール入力→マジックリンクで再アクセス、複数ブランド/イベントの選択。 | Phase 2 |

UIは日本語、スマホ・PC対応。購入枠操作やAI機能の説明など出展準備に不要な操作は追加しない（ブリーフ10章）。
